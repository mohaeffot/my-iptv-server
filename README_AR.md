# MY IPTV SERVER — النسخة الأولية

## محتويات المشروع
- `index.html`: واجهة لوحة التحكم.
- `assets/style.css`: التصميم.
- `assets/app.js`: إدارة القنوات واستيراد/تصدير M3U.
- `data/demo.m3u`: قائمة تجريبية بروابط وهمية غير قابلة للبث.

## تشغيل محلي
افتح `index.html` في متصفح حديث. يمكن استيراد ملف M3U من جهازك، إضافة القنوات وتعديلها وحذفها، ثم تصدير القائمة.

## النشر على GitHub Pages
1. أنشئ مستودعاً باسم `my-iptv-server`.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، مع الحفاظ على مجلد `assets` و`data`.
3. من Settings ثم Pages اختر Deploy from a branch.
4. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
5. انتظر ظهور رابط GitHub Pages وافتحه.

## حدود النسخة الحالية
هذه واجهة Frontend ثابتة فقط:
- لا تنشئ Xtream Codes API.
- لا توفر تسجيل دخول أو حسابات مستخدمين.
- لا تستضيف الفيديو ولا تعيد بثه.
- لا تحتوي على قاعدة بيانات مشتركة بين الأجهزة؛ البيانات تحفظ في Local Storage للمتصفح الحالي.
- قسما الأفلام والمسلسلات مجرد تجهيز للمرحلة التالية.

لإنشاء توافق فعلي مع تطبيق Xtream في الرسيفر، نحتاج لاحقاً إلى Backend مستضاف خارج GitHub Pages، مع واجهات API مناسبة وتوثيق طريقة الطلبات التي يتوقعها تطبيق الرسيفر. لا تفترض أن تطبيق Geant يقبل أي API لمجرد وجود خانات Server URL وUsername وPassword.

## الأمان والحقوق
لا ترفع ملفات M3U الحقيقية أو روابط خاصة أو كلمات مرور إلى مستودع Public. استخدم فقط روابط ومحتوى تملك حق الوصول إليه وتوزيعه. اجعل المستودع Private إذا كانت الملفات تحتوي بيانات غير عامة.
